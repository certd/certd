# 企业模式与项目管理

SaaS 模式以个人账号管理流水线、授权和证书。企业模式以项目组织这些资源，项目成员按权限协作。具备专业版权益的实例可使用企业模式。商业版可以切换，面向外部客户运营的站点适合保留 SaaS 模式。

## 开启企业模式

1. 管理员在「系统管理 → 系统设置 → 管理模式」选择「企业模式」并保存。
2. 在「项目管理」中建立项目，并指定项目管理员。需要一起管理的流水线和授权放在同一个项目。
3. 用户申请加入项目，或由项目管理员在项目详情中添加成员。项目管理员在同一页面审批申请并分配权限。
4. 用户切换到目标项目后查看或管理资源。

| 项目权限 | 可以做什么 |
| --- | --- |
| 查看 | 查看有权限访问的项目资源 |
| 编辑 | 查看或编辑项目资源 |
| 管理 | 管理项目资源和成员，可审批加入申请 |

如果资源为空，先检查当前项目和成员审批状态。此前在 SaaS 模式下创建的个人资源需要迁移到项目后才会出现在项目中。

## 迁移个人数据

1. 切换到目标项目，打开项目详情并选择「个人数据迁移」。
2. 核对迁移对话框显示的资源数量和目标项目。范围包括流水线、运行历史、授权、证书、站点监控、通知、域名等。
3. 确认迁移后，在目标项目检查资源和依赖授权。个人数据迁移不可撤销，操作前可先完成[备份](../backup/)。

## 在项目之间转移流水线

在源项目的流水线列表勾选要转移的记录，点击「转到其他项目」，选择目标项目并确认。操作需要源项目的编辑权限。转移会在目标项目复制任务引用的授权，清空原分组，并改用目标项目的默认通知。转移后检查输出引用、授权、部署目标和通知，如有需要重新分组并运行验证。

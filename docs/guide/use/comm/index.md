## 配置套餐与配额

1. 在「系统管理 → 套餐管理」创建套餐和对应规格，按实例需要设置有效期、流水线和证书等配额。限制泛域名时，在套餐规则中核对泛域名配额。
2. 在「套餐设置」确定是否允许套餐叠加。默认只有一个套餐生效，打开后可同时叠加多个套餐。加量包可以单独叠加。
3. 在「用户套餐」核对生效和到期时间、当前权益，再用测试用户验证购买或分配后的实际配额。

### 发放套餐激活码

管理员在「套餐管理 → 激活码管理」批量生成激活码，选择套餐、时长、数量及可选的兑换截止时间。可导出 CSV 记录批次，按定向渠道发放。用户在购买套餐页面使用激活码兑换，再到自己的套餐页面核对权益。兑换失败时，管理员可按激活码或批次查验是否已使用、已过期或已禁用。

## 手机号注册和短信登录

此功能仅适用于商业版。管理员前往「系统管理 → 系统设置 → 注册设置」，开启手机号注册或手机短信登录，并在登录方式中选择是否默认使用短信。手机号注册需要开启自助注册。

选择阿里云、腾讯云或易发云短信服务后，授权对应云账号，并按设置表单填入签名、验证码模板等已在短信平台审核的配置。选择腾讯云时还需填写应用 ID 和区域。保存设置后，在相同页面填入测试手机号并发送测试短信。确认收到短信，再从登录页测试完整验证码流程。

无法发送时检查所选短信渠道、云账号授权、审核通过的签名和模板编号。短信服务商的签名、模板变量和发送额度由服务商控制，Certd 的测试只验证当前设置能否发出测试消息。

## 配置激励计划与提现

在「套餐管理 → 激励计划设置」启用推广，设置佣金比例，或开启并配置推广等级，再设定最低提现金额、提现渠道和推广协议。用户从「激励计划」复制自己的推广链接，查看推广记录和佣金。

用户在「我的钱包」填写收款信息并提交提现申请。管理员在「提现申请记录」核对渠道、金额和收款信息后处理，用户在钱包查看申请状态。遇到无法提现时，先核对余额、最低金额和站点开放的渠道。

## 管理用户余额

管理员在「套餐管理 → 余额管理」使用「余额充值」，选择用户、填写金额并核对结果。用户可在「我的钱包」查看余额，管理员可在「余额变更记录」查看对应流水。套餐订单、推广佣金和提现记录分别从其列表查询。

# 部署到 SSH 主机

「主机-部署证书到SSH主机」可上传证书，并执行目标主机上的部署脚本。

## 配置并验证

1. 创建 SSH 主机授权，填写目标地址、端口、账号和私钥或密码，点击测试。
2. Certd 无法直连目标时，先创建可直连的跳板机 SSH 授权。在目标主机授权中选择「跳板机SSH授权」，再次测试连接。
3. 在流水线添加主机部署任务，选择证书输出和目标主机授权，填写目标证书、私钥路径。
4. 如服务需要重载，在部署任务配置与目标系统匹配的重载操作。运行一次，查看任务日志并检查站点对外提供的证书。

连接成功但上传失败时，检查目标目录是否存在、账号是否具备写入权限。证书文件更新后站点仍返回旧证书时，核对服务正在读取的路径及重载结果。

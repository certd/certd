# 系统管理页面

系统管理页面的查询需要「系统设置查看」权限，修改或删除需要「系统设置编辑」权限。批量操作前再次核对用户、项目和选中数量。

## 查询用户流水线

前往「系统管理 → 用户数据管理 → 用户流水线管理」。按用户、项目 ID、关键词或流水线类型筛选，表格可查看流水线状态、类型和基本信息，也可导出当前筛选结果。

管理员此处可删除单条流水线。批量删除需要专业版权益。删除前确认流水线所有者及定时触发影响，并在操作后通过审计日志确认记录。

此页面用于查询和管理记录，不提供代替用户编辑流水线或启动任务的操作。需要与用户协作修改任务时，让用户分享流水线详情或在企业模式中使用项目权限。

## 查询用户站点监控

前往「系统管理 → 用户数据管理 → 用户证书监控管理」。按用户、项目 ID、站点名称、域名、证书域名、证书状态或检查状态筛选。导出按钮按当前查询条件导出记录。

遇到某用户报告的监控问题时，可按域名筛选，检查站点地址与端口、证书域名、颁发机构、到期时间、上次检查状态和错误内容。这里是跨用户监控记录管理页，不能用管理员身份替用户直接修复站点、DNS 或网络问题。删除记录前核对所属用户，单条和批量删除均会产生审计记录。

## 授权委托

管理员查看或下载其他用户证书前，该用户需用自己的账号打开「个人资料 → 授权委托设置」，开启「授权管理员查看和下载证书」。该开关默认关闭，需要专业版权益。用户可随时关闭授权。

授权生效后，管理员在对应流水线或证书记录执行查看、下载。未授权时会提示用户先开启授权。此设置只开放证书查看和下载，不开放该用户的云厂商、SSH 或 ACME 授权密钥。需要核查具体操作时查看「系统管理 → 审计日志」。

## 首页公告和页脚

进入「系统管理 → 系统设置 → 基本设置」：

- **系统公告**会显示在首页。保存后刷新首页核对文字和链接。
- **首页启用**控制首页页面是否对外显示。「隐藏首页插件列表」只控制首页的插件列表区域。
- **自定义页脚**仅专业版可用，在页面底部渲染，输入内容支持 HTML。只有可信管理员可编辑，勿粘贴不受信任的 HTML 或脚本。

设置完成后，在登录状态和未登录状态各检查一次目标页面。

## 绑定访问地址

仍在「系统管理 → 系统设置 → 基本设置」，选择「绑定 URL」，将当前浏览器访问地址绑定到地址 1 或地址 2。填写外部用户实际访问的完整地址，包含 `https://`、主机名、必要端口和反向代理路径前缀，例如 `https://cert.example.com/`。

确认域名解析、HTTPS 和代理路由已经可用，再打开绑定对话框绑定当前地址。地址 1 和地址 2 可服务两个访问域名。Certd 生成的通知链接以地址 1 为准，因此应将主要访问地址绑定到地址 1。绑定地址帮助 Certd 生成站内链接，并不负责申请证书、配置 DNS 或设置反向代理。

更换对外域名后同步检查绑定地址、OAuth 提供商回调、反向代理和通知链接。[第三方登录](./oauth.md) · [网络设置与排错](./network.md)

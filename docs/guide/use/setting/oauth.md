# 第三方登录配置

管理员可在「系统管理 → 系统设置 → 第三方登录」启用 OAuth 登录或 Passkey 登录。两项功能均需要专业版权益。

## 配置 OAuth 或 OIDC

1. 使用用户实际访问的 HTTPS 地址打开 Certd。在「第三方登录」启用功能，从对应提供商所在行复制回调地址。
2. 在提供商后台创建网站应用，注册复制的回调地址。协议、域名、端口和路径需要一致。
3. 在 Certd 相应提供商的「第三方登录配置」中创建授权，填入应用凭据，选择该授权并保存。
4. 保留当前管理员会话，用独立浏览器窗口测试登录。确认已有管理员账号能正确绑定后，再考虑开启「自动跳转第三方登录」或「仅使用第三方登录」。

| 提供商 | 应用及所需凭据 |
| --- | --- |
| GitHub / Gitee | 创建 OAuth 应用，填写 Client ID、Client Secret |
| Google | 创建 Web 应用类型的 OAuth 客户端，将回调填入已获授权的重定向 URI |
| Microsoft | 在 Microsoft Entra 注册应用，添加 Web 回调，填写应用 ID、客户端密钥值及适用的 Tenant ID |
| OIDC | 创建机密 Web 客户端，填写 Client ID、Client Secret 及 Issuer 地址 |
| 微信扫码 | 使用微信开放平台网站应用的 App ID、App Secret，并配置回调域名 |
| 彩虹聚合登录 | 填写聚合服务地址、App ID、App Key，选择启用的登录渠道 |

OIDC 的「服务地址」填写 Issuer，通常是服务发现地址去掉 `/.well-known/openid-configuration` 后的部分。多个 OAuth 提供商使用各自的回调地址。

「自动注册用户」开启后，首次使用未绑定的第三方账号会创建 Certd 用户。关闭时由用户选择。现有账号可先登录 Certd，在个人资料绑定第三方账号，再退出测试第三方登录。

首次自动注册的用户名由第三方昵称加随机后缀和提供商标识组成，邮箱则使用提供商返回的邮箱信息。登录后个人资料可能提示尚未设置密码，按提示设置后，该用户可继续使用密码登录。账号密码由用户自己设置，不由 OAuth 提供商决定。

### 登录失败

- 提示回调地址不匹配时，从实际访问地址重新复制回调，检查提供商的回调配置与反向代理的 HTTPS 设置。
- 提示应用凭据错误时，检查提供商、租户、应用类型和密钥是否匹配。Microsoft 的客户端密钥填写密钥**值**。
- 已开启仅第三方登录但无法进入时，服务重启后的前 10 分钟可在同一站点访问 `/#/login?oauthOnly=false`，用密码登录后修正配置。[恢复登录步骤](../forgotpasswd/)

## 配置 Passkey

1. 管理员通过 HTTPS 打开系统设置，开启「Passkey 登录」并保存。
2. 用户登录后，在个人资料的 Passkey 区域添加凭据，按浏览器提示使用设备或安全密钥完成注册。
3. 保留当前会话，在相同域名验证 Passkey 登录。通过两个域名访问同一实例时，请分别在两个域名注册。

Passkey 绑定注册时的访问域名。如果更换域名，先用可用的登录方式进入新地址，再注册新的 Passkey。浏览器无法添加凭据时，先确认地址为 HTTPS，并核对是否使用了注册时的域名。

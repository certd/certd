# 已有证书托管与远程拉取

适合证书由其它系统或人工签发、Certd 负责部署的场景。先准备证书和配套的私钥，再选一种来源。

## 手动上传已有证书

1. 在流水线列表点击 **已有证书托管**，填写证书覆盖的域名，按表单上传证书与私钥。
2. 在 **过期前提醒** 填写提前天数，在后续阶段添加部署任务并引用 **域名证书** 输出。
3. 保存并运行。证书过期或在配置的提醒阈值内时，托管任务报错并停止部署。拿到新证书后，编辑同一任务，替换证书与私钥后再次运行。

## 从远端拉取证书

1. 在流水线列表点击 **添加更多流水线 → 拉取证书部署**。可选来源包括 HTTP/HTTPS、阿里云 OSS、腾讯云 COS、七牛云 KODO、S3/MinIO、SFTP 和 FTP。
2. 选择 **来源授权**，分别填写 **证书路径** 和 **私钥路径**。证书使用 PEM 完整链，例如 `fullchain.pem`，私钥使用匹配的 PEM 文件，例如 `privkey.pem`。对象存储填对象键，SFTP 或 FTP 填文件路径，均需包含文件名。
3. HTTP/HTTPS 使用授权时可填相对授权 URL 的路径，或填写同源完整 URL。省略授权时填完整文件 URL。应限制私钥来源的访问权限。
4. 填写证书覆盖的域名，添加部署任务、引用 **域名证书** 输出，再配置定时运行。首次手动运行，检查日志与目标证书。

拉取结果与上次相同且配置未变时，任务复用原证书输出并跳过更新。证书已过期或证书与私钥不匹配时，任务报错并停止部署。遇到 404 或拒绝访问，先从 Certd 所在网络检查来源地址、授权和文件名，再确认来源提供的是 PEM 文件。

# IP 证书申请

用 Certd 可以为公网 IPv4 或 IPv6 地址申请 Let's Encrypt 证书。这类证书的有效期为 160 小时。建议每天运行流水线，把到期前更新天数设为 2 天。[Let's Encrypt 的 IP 证书说明](https://letsencrypt.org/2026/01/15/6day-and-ip-general-availability)

## 配置申请

1. 在流水线列表点击 **创建证书流水线**，在域名输入框填写 IP 地址，例如 `192.0.2.10`。填写 IPv6 时直接输入地址。
2. 颁发机构选 **Let's Encrypt**。要先测试验证流程，可选 **Let's Encrypt 测试环境**，签出的测试证书不会被浏览器默认信任。
3. 验证方式选 **HTTP 文件验证**。配置上传授权和该 IP 实际对外提供 HTTP 服务的网站根路径。CA 必须能通过公网 80 端口访问验证文件。详见 [HTTP 文件验证](./validation.md#http-文件验证)。
4. 保存流水线并添加部署任务，手动执行一次，确认目标站点提供新证书，再添加定时触发器。

如果日志显示证书有效期短于配置的更新天数，Certd 会调整短期证书的实际更新阈值，避免每次运行都重新申请。可在申请任务中调整更新天数，并在日志中核对下次更新判断。

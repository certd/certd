### 3. 申请和部署第一张证书

1. 准备一个自己能修改 DNS 的域名。在 Certd 创建 DNS 服务商授权并测试连接。
2. 点击「创建证书流水线」，填入域名，选择 Let's Encrypt 和 DNS 验证，选择刚创建的授权。保存后运行一次，在运行记录确认验证与签发成功。[证书申请指南](./use/cert/)
3. 添加目标平台的部署任务，选择目标授权，并引用上游任务输出的证书。再次运行，在目标站点确认 HTTPS 已提供该证书。
4. 设置定时触发和失败通知，再用[站点证书监控](./use/monitor/)检查实际对外生效的证书。

申请失败时，先在运行记录打开失败步骤。DNS 验证失败可核对域名是否由所选服务商托管、授权是否具备读写解析记录的权限，以及 TXT 是否已生效。部署失败可先测试目标授权，再检查任务选择的证书和站点。[常见问题](./qa/use.md)
